# ConvoChat

A simple real-time chat app. Join with your name and start messaging instantly.

## Quick Start

```bash
npm install
npm run dev    # Dev mode with auto-reload
npm start      # Production mode
```

Open `http://localhost:3000`

## Features

- Simple registration (1-20 character names)
- Real-time messaging
- Online users list
- Join/leave notifications
- Clean black & white design
- Mobile responsive

## Scripts

- `npm run dev` - Dev with auto-reload
- `npm run build` - Compile TypeScript
- `npm start` - Run server
- `npm run clean` - Clear dist folder

## How to Use

1. Enter your name and click "Join"
2. Type a message and press Enter
3. See online users in the sidebar
4. Click "Leave" to disconnect

## Tech Stack

- Express.js + Socket.IO backend
- TypeScript
- Vanilla HTML/CSS/JavaScript frontend
- Node.js v18+

## Config

```bash
PORT=8080 npm start    # Change port
```
